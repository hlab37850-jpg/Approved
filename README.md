# Approved — محاسب برو

مشروع Android جديد لإعادة تنفيذ واجهات وتجربة استخدام تطبيق المحاسب المرجعي بالاستناد إلى التحليل المتاح في [almahaseb-pro-apk-analysis](https://github.com/hlab37850-jpg/almahaseb-pro-apk-analysis).

> تنبيه: المستودع المرجعي يحتوي على ملفات APK مفككة (مصادر وموارد)، وليس مشروع Android الأصلي القابل للبناء مباشرة. لذلك يجب إعادة تنفيذ الواجهات والوظائف من التحليل، ولا يعني وجود هذه البداية أن التطابق الكامل تحقق بالفعل.

## التقنية
- Kotlin + Android native
- Jetpack Compose / Material 3 كبداية قابلة للتطوير
- GitHub Actions للبناء السحابي فقط

## الحالة
المرحلة الأولى: إنشاء هيكل بناء قابل للتحقق، ثم توسيع الشاشات ومطابقتها مع موارد المصدر. لا تُستخدم بيانات محاسبية تجريبية باعتبارها بيانات حقيقية.

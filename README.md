# Approved — المحاسب العربي

تطبيق Android عربي لإدارة الحسابات والمخزون، يُعاد بناؤه تدريجياً استناداً إلى الفيديو المرجعي ومواصفات المشروع.

## التقنية
- Kotlin + Jetpack Compose
- SQLite محلية
- اختبارات Kotlin
- GitHub Actions لبناء APK في السحابة فقط

## مبادئ أساسية
- قاعدة بيانات فارغة عند أول تشغيل، دون بيانات تجريبية ثابتة.
- واجهة RTL وأشرطة زرقاء وجداول مضغوطة.
- فصل الواجهة عن منطق الحسابات وقاعدة البيانات.
- لا تُعلن أي ميزة مكتملة إلا بعد تنفيذها والتحقق منها.
- نجاح البناء لا يعني تلقائياً اكتمال كل الميزات.

## البناء
يُبنى المشروع عبر GitHub Actions: تبويب Actions ثم تشغيل سير Android Cloud Build أو دفع تغيير إلى الفرع main. ملف APK الناتج يُحفظ كـ artifact باسم `approved-debug-apk`.
